# cre-ation website

A fully static Astro site for https://cre-ation.io. Original artwork, page URLs,
menu links and motion are preserved. No application server is needed in production.

## Run locally

Use Node.js 24 LTS, then:

```sh
npm ci
npm run dev
```

Open http://localhost:4321. To check the production site:

```sh
npm run build
npm run preview
```

## Editing

- `src/pages/`: home, contact, work index and six individual case studies.
- `src/layouts/Site.astro`: shared document, metadata and assets.
- `src/components/`: navigation menus.
- `src/styles/site.css`: original visual styling.
- `src/styles/responsive.css`: phone/desktop layout and scroll snapping.
- `src/scripts/site.js`: menu focus handling and section reveals.
- `public/assets/`: original artwork, unchanged.
- `public/CNAME`: existing custom domain.

Phone layouts retain the original full-width portrait artwork. At 1000px and wider,
all sections switch to native landscape compositions: real text, multiple columns,
and artwork details displayed through SVG viewports from the unchanged originals.
The contact page also switches to a two-column layout. Sections fill the viewport,
and can grow on short screens or with larger text settings. Native proximity scroll
snapping gently settles on sections; reduced-motion preferences disable animations.

Desktop content is in `src/components/DesktopPanel.astro` and `src/data/work.ts`;
its styles are in `src/styles/desktop.css`. Mobile artwork remains in `public/assets/`.

`dist/` is generated by Astro and should not be edited or committed. Every push to
`main` builds the site and deploys `dist/` to GitHub Pages. The old OpenAI Sites copy
remains a temporary migration fallback.
